CS4433 — Moderated Learning Management System

Individual Software Engineering Project
National University of Lesotho

This repository contains the development of the Moderated Learning Management System for CS4433 Software Engineering.

The project follows the Waterfall development model with V-Model verification and validation.

Project Phases
Phase 1 — Project Planning and Management
Phase 2 — Requirements Engineering
Phase 3 — System Design
Phase 4 — Implementation
Phase 5 — Verification and Validation
Phase 6 — Deployment
Phase 7 — Maintenance and Completion
